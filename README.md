# Fleet Rental Management System (FRMS)

## Overview
A Java console application developed for the Object-Oriented Programming (ITS 1033) coursework. It manages vehicles, customers, and rental agreements.

## Technologies
- Java
- IntelliJ IDEA
- Java Collections
- Object-Oriented Programming

## Features
- User login
- Vehicle and customer management
- Rental agreement creation and returns
- Vehicle availability checking
- Rental history
- Input validation

## How to Run
1. Open the project in IntelliJ IDEA.
2. Ensure JDK 25 or later is configured, as required by the coursework.
3. Open `src/lk/ijse/fleet/Main.java`.
4. Run the `Main` class.
